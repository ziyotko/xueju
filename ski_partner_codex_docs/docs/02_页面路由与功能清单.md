# 页面路由与功能清单

## 1. 小程序端页面

### 1.1 首页 /pages/index/index

功能：
- 展示滑雪局列表
- 支持城市切换
- 支持关键词搜索
- 支持日期、雪场、水平、单双板、拼车、拼房、同性局筛选
- 支持推荐/最新排序
- 底部导航：发现、我的行程、发布、消息、我的

页面模块：
- 顶部城市选择
- 搜索框
- Banner
- 快捷筛选入口
- 滑雪局卡片列表
- 底部 TabBar

卡片字段：
- 雪场名称
- 日期
- 出发地
- 水平要求
- 单双板
- 玩法标签
- 人数状态
- 发起人头像
- 信用评分
- 加入按钮

### 1.2 发布滑雪局 /pages/event/create

功能：
- 创建滑雪局
- 表单校验
- 发布成功跳转详情页

字段：
- 雪场
- 出发日期
- 出发地
- 集合时间
- 集合地点
- 交通方式
- 人数上限
- 水平要求
- 单双板要求
- 玩法标签
- 是否可拼车
- 是否可拼房
- 是否互拍
- 是否接受新手
- 是否限同性
- 费用说明
- 备注

### 1.3 滑雪局详情 /pages/event/detail?id=

功能：
- 查看滑雪局详情
- 申请加入
- 收藏
- 分享
- 举报
- 发起人审核入口
- 成员列表
- 局内规则

页面模块：
- 顶部雪场图片
- 标题与状态
- 基础信息
- 人数信息
- 发起人信息
- 已加入成员
- 局内规则
- 底部固定按钮：收藏/申请加入/进入群聊

### 1.4 申请加入 /pages/event/apply?eventId=

功能：
- 提交加入申请
- 填写自我介绍
- 说明自己水平和交通方式
- 展示自己的默认资料

字段：
- 我的滑雪水平
- 单双板
- 是否开车
- 是否能带人
- 出发位置
- 申请说明

### 1.5 加入申请审核 /pages/event/applications?eventId=

功能：
- 发起人查看申请列表
- 同意/拒绝申请
- 查看申请人主页

### 1.6 我的行程 /pages/trip/index

Tabs：
- 我发起的
- 我加入的
- 待确认
- 已结束

功能：
- 查看行程状态
- 进入详情
- 进入群聊
- 滑后评价

### 1.7 局内群聊 /pages/chat/room?eventId=

MVP 功能：
- 查看消息列表
- 发送文本消息
- 系统消息
- 快捷功能入口：
  - 集合信息
  - 费用说明
  - 雪票链接
  - 行程备注
  - 位置
  - 投票，预留

MVP 可做成普通消息流，不要求 WebSocket，先用轮询或页面刷新。

### 1.8 个人主页 /pages/user/profile?id=

功能：
- 查看用户资料
- 查看滑雪标签
- 查看信用评分
- 查看历史评价
- 关注按钮，预留
- 举报按钮

字段：
- 头像
- 昵称
- 性别，可隐藏
- 所在城市
- 单双板
- 滑雪水平
- 常去雪场
- 滑行风格
- 认证状态
- 发起局数量
- 参与局数量
- 好评率

### 1.9 我的资料编辑 /pages/user/edit

功能：
- 编辑个人资料
- 选择滑雪水平
- 设置常去雪场
- 设置风格标签

### 1.10 滑后评价 /pages/review/create?eventId=&userId=

功能：
- 对同局成员评价
- 正向标签
- 负向标签
- 文本评价
- 匿名开关，预留

正向标签：
- 准时
- 友好
- 水平真实
- 沟通顺畅
- 安全意识好
- 愿意再次同滑

负向标签：
- 爽约
- 迟到严重
- 水平虚假
- 临时改计划
- 言语不适
- 危险行为

### 1.11 登录页 /pages/auth/login

功能：
- 微信授权登录
- 手机号授权，预留
- 首次登录引导完善资料

## 2. 管理后台页面

### 2.1 用户管理 /admin/users
- 用户列表
- 查看详情
- 禁用/启用用户
- 查看评价和举报

### 2.2 滑雪局管理 /admin/events
- 滑雪局列表
- 查看详情
- 下架/恢复
- 状态筛选

### 2.3 加入申请管理 /admin/applications
- 查看申请记录
- 状态筛选

### 2.4 举报管理 /admin/reports
- 举报列表
- 处理举报
- 标记处理结果

### 2.5 评价管理 /admin/reviews
- 查看评价
- 隐藏恶意评价

### 2.6 字典管理 /admin/dicts
- 雪场
- 城市
- 水平
- 玩法标签
- 交通方式
