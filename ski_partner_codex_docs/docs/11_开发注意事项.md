# 开发注意事项

## 1. 不要做偏

这个产品不是滑雪交友软件，而是滑雪行程组局工具。

页面文案尽量使用：
- 组局
- 同滑
- 滑雪局
- 同水平
- 同雪场
- 拼车
- 拼房
- 互拍

不要使用：
- 脱单
- 约会
- 附近的人
- 帅哥美女
- 私密社交

## 2. 第一版可以简化的地方

### 聊天
可以先做普通消息表，不做 WebSocket。  
小程序进入页面时拉取消息，发送后刷新即可。

### 微信登录
如果微信真实 code 换 openid 暂时不好调试，可以先用 mock login。  
但代码结构要保留真实微信登录入口。

### 图片
雪场图、头像可先用静态 mock 图片。

### 实名认证
第一版不强制做，保留字段。

### 手机号认证
第一版不强制做，保留字段。

## 3. 必须做好的地方

- 状态流转
- 权限校验
- 重复申请校验
- 满员校验
- 发起人审核权限
- 成员才能聊天
- 已结束才能评价
- 同局成员才能评价
- 举报入口预留

## 5. 命名建议

数据库字段使用 snake_case。  
前端字段使用 camelCase。  
接口层做字段映射。

示例：
- 数据库：event_date
- 接口返回：eventDate
