# 权限与安全策略

## 1. 用户权限

### 游客
- 可浏览滑雪局列表
- 可查看滑雪局详情
- 不可申请
- 不可发布
- 不可聊天
- 不可评价

### 登录用户
- 可发布滑雪局
- 可申请加入
- 可进入已加入的局内消息
- 可评价同局成员
- 可举报

### 发起人
- 可编辑自己发起的滑雪局
- 可取消自己发起的滑雪局
- 可审核加入申请
- 可结束滑雪局
- 可移除成员，预留

### 管理员
- 可查看后台
- 可禁用用户
- 可下架滑雪局
- 可处理举报
- 可隐藏评价

## 2. 接口鉴权

所有需要登录的接口必须校验 JWT：

```text
Authorization: Bearer <token>
```

需要登录：
- 发布滑雪局
- 申请加入
- 审核申请
- 发送消息
- 创建评价
- 提交举报
- 我的行程
- 我的资料

不强制登录：
- 滑雪局列表
- 滑雪局详情
- 雪场字典
- 标签字典

## 3. 数据权限

- 用户只能修改自己的资料。
- 发起人只能修改自己的滑雪局。
- 发起人只能审核自己滑雪局的申请。
- 用户只能查看自己参与的局内消息。
- 用户只能评价同局成员。
- 管理员接口必须有 admin 权限。

## 4. 风险控制

### 防骚扰
- 支持举报用户。
- 支持后台禁用用户。
- 支持隐藏异常评价。
- 预留黑名单表。

### 防爽约
- 滑后评价记录爽约标签。
- 用户主页展示好评率、准时标签。
- 后续可加入爽约次数。

### 防虚假水平
- 滑后评价可标记水平虚假。
- 用户主页展示历史评价标签。

### 防擦边社交
产品文案不要强调：
- 脱单
- 约会
- 帅哥美女
- 附近的人
- 私密交友

产品文案应强调：
- 同雪场
- 同时间
- 同水平
- 组局
- 拼车
- 拼房
- 互拍
- 安全同行

## 5. 内容审核

MVP 可先做后台人工处理举报。  
后续可接入文本内容安全接口。

需要审核的内容：
- 用户昵称
- 个人简介
- 滑雪局备注
- 聊天消息
- 评价内容
- 举报内容
