# UI 设计规范

## 1. 设计关键词

- 干净
- 年轻
- 运动感
- 冰雪感
- 卡片化
- 轻社交
- 安全可信

## 2. 主色

建议：
- 主色：#4F46E5
- 辅助蓝：#2563EB
- 冰雪浅蓝：#EFF6FF
- 成功绿：#22C55E
- 警示橙：#F59E0B
- 错误红：#EF4444

## 3. 背景

- 页面背景：#F6F8FC
- 卡片背景：#FFFFFF
- 弱分割线：#EEF0F5

## 4. 字体层级

- 页面标题：18px / 600
- 卡片标题：16px / 600
- 正文：14px / 400
- 辅助文字：12px / 400
- 数字强调：20px / 700

## 5. 圆角

- 大卡片：16px
- 普通卡片：12px
- 标签：999px
- 按钮：12px

## 6. 阴影

卡片阴影：
- 0 6px 20px rgba(15, 23, 42, 0.06)

不要使用过重阴影。

## 7. 标签样式

### 水平标签
- 新手：浅蓝
- 初级：浅绿
- 中级：浅紫
- 高级：浅橙

### 状态标签
- 招募中：绿色
- 已满员：灰色
- 已结束：灰色
- 已取消：红色
- 待审核：橙色

## 8. 页面结构

首页：
- 顶部城市 + 搜索
- Banner
- 快捷筛选
- Tab：推荐/最新
- 滑雪局卡片

发布页：
- 分组表单卡片
- 基本信息
- 滑雪信息
- 其他需求
- 底部固定发布按钮

详情页：
- 顶部大图
- 详情卡片
- 发起人卡片
- 成员卡片
- 规则卡片
- 底部固定操作栏

## 9. 交互规范

- 申请加入前需要登录
- 发布滑雪局前需要完善资料
- 加入自己发起的局不允许
- 满员后不可申请
- 已结束的局不可申请
- 发起人不能审核自己的申请
- 评价只能在滑雪局结束后进行
