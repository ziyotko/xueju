# 开发阶段任务拆分

## 阶段 0：项目初始化

目标：
- 跑通小程序端、后端、管理后台
- 建立目录结构
- 配置环境变量

任务：
- 初始化 Go/Gin 项目
- 配置 MySQL 连接
- 配置 JWT
- 初始化微信小程序或 uni-app 项目
- 初始化 Vue3 + Element Plus 后台
- 建立统一接口请求封装
- 建立统一错误处理

验收：
- 后端可启动
- 小程序可启动
- 后台可启动
- `/api/health` 返回成功

## 阶段 1：数据库与基础接口

目标：
- 完成核心表结构和字典数据

任务：
- 创建 users
- 创建 ski_resorts
- 创建 ski_events
- 创建 event_members
- 创建 join_requests
- 创建 chat_messages
- 创建 reviews
- 创建 reports
- 插入假数据
- 实现字典接口

验收：
- SQL 可执行
- 字典接口可返回数据
- 示例滑雪局可查询

## 阶段 2：用户与登录

目标：
- 实现用户登录和资料维护

任务：
- 微信登录接口
- JWT 生成和校验
- 获取当前用户
- 编辑个人资料
- 用户主页接口

验收：
- 用户可登录
- 可编辑资料
- 可查看他人主页

## 阶段 3：滑雪局核心

目标：
- 实现发布、列表、详情

任务：
- 滑雪局列表接口
- 筛选条件
- 滑雪局详情接口
- 创建滑雪局接口
- 编辑滑雪局接口
- 取消滑雪局接口
- 小程序首页
- 发布页
- 详情页

验收：
- 用户可发布滑雪局
- 首页能看到滑雪局
- 可以进入详情页
- 筛选可用

## 阶段 4：申请加入与审核

目标：
- 完成组局闭环

任务：
- 申请加入接口
- 申请列表接口
- 同意申请接口
- 拒绝申请接口
- 我的行程接口
- 申请加入页面
- 审核申请页面
- 我的行程页面

验收：
- 用户可申请加入
- 发起人可审核
- 同意后进入成员列表
- 满员状态自动变化

## 阶段 5：局内消息

目标：
- 实现简单群聊

任务：
- 消息列表接口
- 发送消息接口
- 进入群聊权限校验
- 小程序群聊页面
- 系统消息

验收：
- 成员可发送消息
- 非成员不可进入
- 消息按时间排序展示

## 阶段 6：评价与信用

目标：
- 滑后评价闭环

任务：
- 结束滑雪局接口
- 创建评价接口
- 用户评价列表接口
- 信用评分更新逻辑
- 滑后评价页面
- 个人主页展示评价

验收：
- 只有已结束滑雪局可评价
- 只能评价同局成员
- 重复评价被拦截
- 用户主页展示评价信息

## 阶段 7：举报与后台

目标：
- 完成基础运营管理

任务：
- 举报接口
- 后台登录
- 用户管理
- 滑雪局管理
- 举报管理
- 评价管理
- 下架滑雪局
- 禁用用户

验收：
- 管理员可以处理风险内容
- 前台不展示下架内容
- 禁用用户不能继续操作

## 阶段 8：优化与上线准备

目标：
- 修复体验问题，准备上线

任务：
- 空状态优化
- 加载状态优化
- 错误提示统一
- 表单校验完善
- 页面适配
- 埋点预留
- README 启动说明
- 接口测试文档

验收：
- 全流程可跑通
- 无明显 UI 错位
- 关键接口有错误处理
- 示例账号可完整体验
