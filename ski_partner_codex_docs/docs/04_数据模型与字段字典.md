# 数据模型与字段字典

## 1. users 用户表

表名：users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 用户 ID |
| openid | VARCHAR(128) | 微信 openid |
| unionid | VARCHAR(128) | 微信 unionid，可空 |
| nickname | VARCHAR(64) | 昵称 |
| avatar_url | VARCHAR(255) | 头像 |
| gender | TINYINT | 0未知 1男 2女 |
| gender_visible | TINYINT | 性别是否公开 |
| phone | VARCHAR(32) | 手机号，可空 |
| city | VARCHAR(64) | 常驻城市 |
| ski_type | VARCHAR(32) | snowboard/ski/both |
| ski_level | VARCHAR(32) | beginner/primary/intermediate/advanced |
| style_tags | JSON | 滑行风格标签 |
| favorite_resorts | JSON | 常去雪场 |
| has_car | TINYINT | 是否有车 |
| credit_score | DECIMAL(3,1) | 信用评分 |
| event_count | INT | 发起局数量 |
| join_count | INT | 参与局数量 |
| good_rate | DECIMAL(5,2) | 好评率 |
| status | VARCHAR(32) | normal/disabled |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| deleted_at | DATETIME | 删除时间，可空 |

## 2. ski_resorts 雪场表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 雪场 ID |
| name | VARCHAR(128) | 雪场名称 |
| city | VARCHAR(64) | 所在城市 |
| province | VARCHAR(64) | 省份 |
| image_url | VARCHAR(255) | 图片 |
| status | VARCHAR(32) | normal/disabled |
| sort | INT | 排序 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

## 3. ski_events 滑雪局表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 滑雪局 ID |
| title | VARCHAR(128) | 标题 |
| creator_id | BIGINT | 发起人 ID |
| resort_id | BIGINT | 雪场 ID |
| resort_name | VARCHAR(128) | 雪场名称冗余 |
| event_date | DATE | 滑雪日期 |
| start_time | DATETIME | 集合时间 |
| depart_city | VARCHAR(64) | 出发城市 |
| depart_area | VARCHAR(128) | 出发区域 |
| meet_place | VARCHAR(255) | 集合地点 |
| traffic_type | VARCHAR(32) | self_drive/high_speed_rail/bus/other |
| max_members | INT | 人数上限 |
| current_members | INT | 当前人数 |
| ski_type_req | VARCHAR(32) | 单双板要求 |
| level_req | VARCHAR(32) | 水平要求 |
| purpose_tags | JSON | 玩法标签 |
| allow_beginner | TINYINT | 是否接受新手 |
| same_gender_only | TINYINT | 是否限同性 |
| allow_car_pool | TINYINT | 是否拼车 |
| allow_room_share | TINYINT | 是否拼房 |
| allow_photo | TINYINT | 是否互拍 |
| cost_desc | VARCHAR(255) | 费用说明 |
| remark | TEXT | 备注 |
| status | VARCHAR(32) | recruiting/full/finished/cancelled/removed |
| view_count | INT | 浏览量 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| deleted_at | DATETIME | 删除时间，可空 |
