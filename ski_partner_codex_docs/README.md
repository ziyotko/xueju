# 雪局 - Codex 开发交接文档包

项目定位：滑雪搭子/滑雪组局小程序 MVP

一句话说明：按雪场、日期、水平、出发地，快速找到靠谱雪友一起滑雪、拼车、拼房、互拍。

## 推荐开发顺序

1. 先阅读 `00_Codex总提示词.md`
2. 再阅读 `01_PRD产品需求文档.md`
3. 按 `10_开发阶段任务拆分.md` 分阶段实现
4. 前端页面按 `02_页面路由与功能清单.md` 开发
5. 后端接口按 `05_API接口约定.md` 开发
6. 数据库按 `04_数据模型与字段字典.md` 建表
7. 测试验收按 `08_测试用例与验收标准.md`

## MVP 范围

第一阶段只做“滑雪组局”，不做复杂社区、不做雪票交易、不做轨迹记录、不做短视频、不做完整 IM。

核心闭环：

发布滑雪局 → 用户申请加入 → 发起人审核 → 加入局内群聊/联系方式 → 滑后评价 → 信用沉淀。
