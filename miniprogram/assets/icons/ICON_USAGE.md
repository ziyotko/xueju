# Icon 使用清单

小程序端统一通过 `/components/app-icon/` 引用图标。通用图标使用 TDesign Miniprogram Icons，滑雪业务专属图标使用 `/assets/icons/` 下的统一线性本地资源。TabBar 因小程序限制使用 `/assets/icons/tabbar/` 下的 PNG。

## TabBar

- 首页/发现：`home`
- 我的行程：`calendar`，TabBar 文件名使用 `trip.png` / `trip-active.png`
- 发布：`add-circle`，预留 `publish.png` / `publish-active.png`
- 消息：`chat`
- 我的：`user`

## 滑雪局卡片

- 雪场：`location`
- 日期：`calendar`
- 出发地：`location`
- 拼车：`vehicle`（对应业务语义：car）
- 人数：`usergroup`
- 水平：`chart`
- 单板/双板：`snowboard` / `ski`，`source="local"`
- 费用：`wallet`
- 评价：`star`
- 安全：`user-safety`（对应业务语义：shield）

## 操作按钮

- 搜索：`search`
- 筛选：`filter`
- 收藏：`star`
- 分享：`share`
- 举报：`flag`
- 返回：`chevron-left`
- 更多：`more`
- 设置：`setting`
- 编辑：`edit`
- 删除：`delete`
- 关闭：`close`

## 状态

- 招募中：`check-circle`
- 已满员：`usergroup`
- 已结束：`time`
- 已取消：`close-circle`
- 待审核：`time`
- 已通过：`check-circle`
- 已拒绝：`close-circle`
