# SNOWMEET Frontend Assets

这是一套适合前端直接使用的资源包，包含透明 PNG 与 SVG。

## 目录
- svg/
  - SNOWMEET_logo_preserve_shape_cleaned.svg
  - SNOWMEET_symbol_preserve_shape_cleaned.svg
  - SNOWMEET_wordmark_preserve_shape_cleaned.svg
- png/full/
  - snowmeet-logo@1x.png
  - snowmeet-logo@2x.png
  - snowmeet-logo@3x.png
  - snowmeet-logo-web.png
- png/symbol/
  - snowmeet-symbol@1x.png
  - snowmeet-symbol@2x.png
  - snowmeet-symbol@3x.png
  - snowmeet-symbol-web.png
- png/wordmark/
  - snowmeet-wordmark@1x.png
  - snowmeet-wordmark@2x.png
  - snowmeet-wordmark@3x.png

## 说明
- 所有 PNG 均为透明背景，适合网页、前端、小程序宣传页。
- `@1x / @2x / @3x` 适合常见前端资源引用。
- `symbol` 适合 favicon、头像、icon。
- `full` 适合页头、宣传页、门户首页。
- `wordmark` 适合单独展示品牌英文名。
